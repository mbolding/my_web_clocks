The program


        
BQN is Marshall Lochbaum's modern descendant of APL. Each glyph is a primitive, coloured by its role: functions act on arrays, and 1-modifiers and 2-modifiers build new functions from old. Names that start with a capital letter are functions too. Each second the page sets t to the time and runs the lines on the left. The interpreter is BQN's own reference implementation in JavaScript, running here in your browser. Character arrays are shown as plain text, everything else the way BQN's REPL shows it.
