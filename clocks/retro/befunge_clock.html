The program

        
Befunge, invented by Chris Pressey in 1993, is a language whose program is a grid of characters, 80 by 25, and whose instruction pointer moves across it in any of four directions, wrapping round the edges. > v < ^ turn it, digits push numbers onto a stack, and p writes a character anywhere in the grid, including into the program itself.

        
This program loops round a rectangle. Along the top it reads the hours with &, splits them into two digits with 25*/ and 25*%, turns each into a character code with 68*+, and puts them into row 1 with p; then the same for the minutes. The bottom row does the seconds, written backwards because the pointer reads it right to left. The clock you see is the program's own row 1, rewritten on every lap.

        
Each & asks the page for a number, and the page answers with the hours, then the minutes, then the seconds. At 400 steps a second a lap, 102 steps, takes about a quarter of a second; slow it down to watch the pointer, and the clock falls behind until you speed it up again.
