The shader


            
        

        

        
A fragment shader is a small program the graphics card runs once for every pixel, all of them at the same time, with no way for one pixel to ask another what it found. So nothing here draws a hand. Each pixel works out how far it is from each hand, from the time in u_time alone, and colours itself by that distance. Switch to the distance field to see the numbers every pixel computed.

        
The text above is the program the page compiles. Edit it and it recompiles as you type; if it fails, the last good version keeps running and the error is shown. Try changing 0.50 in the hour hand, or the colours at the end. Reset puts the shader back.

        
The other shaders keep the same inputs and the same idea. Ink wash roughens each distance with noise and lets it soak into paper. Metaballs joins the hands with a smooth minimum, so they merge as they pass. Brass is 3D: each pixel marches a ray through a scene made of distance functions and lights whatever it lands on; its second view shows how many steps each ray took.
