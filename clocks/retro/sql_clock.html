The program


        
SQL describes what a result should contain, not how to work it out, and it has no loops. So the face is a table: a recursive common table expression counts out every cell of a 41 by 21 grid, each cell works out from SQLite's own clock whether it lies on a hand, a numeral or the rim, and group_concat joins each row of cells into a line of text. The 21 rows of that result are the picture.

        
The database is sql.js, SQLite compiled to WebAssembly and running in this page. Nothing you type leaves the page; the database lives in memory and is gone when you reload.
