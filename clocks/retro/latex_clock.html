Abstract

We report a real-time determination of the present moment, accurate to the nearest second. The method requires no apparatus beyond a system clock, and the result is reproducible by any observer sharing the reader's time zone.

Keywords: chronometry, real-time analysis, the present

1  Preliminaries

Let h, m, s ∈ ℤ denote the current hour, minute, and second respectively, each updated automatically as the ambient moment advances.

2  Main Result
