Language reference

states { rest #11181c firing #ffb020 }
Declares the state set, in order. The first state is the background state. Colours are optional. Declare states before init and rules.

options { seed 12 order sync }
seed fixes every random draw. order is sync (all nodes update from the same snapshot) or random (one random sweep, updates visible immediately).

graph { ... } builds nodes and directed edges, top to bottom. Each generator appends a fresh block of nodes.
nodes n · ring n · path n · grid w h (add torus to wrap) · random n k (k out-edges each) · debruijn k len · chords k (adds i → i+k over all nodes) · edge a -> b · bidir (mirror every edge so far) · layout circle|grid|force

init { ... }
all rest · node 12 = firing (several indices allowed) · random firing 0.02 · set firing where id % 30 == 0

rules { from -> to when condition }
Rules are tried top to bottom; the first match wins, otherwise the node holds. from may be * for any state. when is optional.

In an expression: inc(s) in-neighbours in state s, outc(s) out-neighbours, nbc(s) both, pop(s) whole graph. state, id, step, indeg, outdeg, deg, n. rand(), min, max, abs, floor, sqrt. Operators + - * / %, == != < <= > >=, and or not. A state name is its own index, so state == firing works.

Comments start with //. Click a node in the graph to change its state by hand.
